Try the real loop

These commands run in your terminal. This tutorial never sends a real message or changes an artifact.

  1. Publish a complete directory with a root index.html or index.md.
    r3 create --kind html --dir ./artifact --title "Weekend guide"
  2. Register for feedback, or wait for it from a generic agent.
    r3 listen <artifact_id>
r3 watch <artifact_id>
  3. Read the feedback and claim the items you will handle.
    r3 prompt <artifact_id>
r3 claim <feedback_id>
  4. Edit locally, publish the complete directory, and reply by stable feedback ID.
    r3 publish <artifact_id> --dir ./artifact
r3 reply <feedback_id> --version 2 --view rendered -m "Updated the reading estimate."

Inspect the original target in its explicit version and representation. Agents use distinct logical sessions. A successful reply releases your claim; the human controls resolution. Use r3 guide for the full contract.
