## Read and navigate

Markdown opens as a document; code opens as highlighted source. Switch HTML or Markdown between **Rendered** and **Source** when you need the other view.

Use the file panel or **Jump to file** to move around. Fold finished sections and mark files viewed to track your progress. Download files that need another app.

## Point at the right detail

Select a passage to discuss its meaning, source lines to discuss exact text, or the whole file for a broader concern. Your draft keeps its target when you switch views.

Use the version selector to revisit earlier snapshots. To review code changes line by line, ask for a [diff](/docs/diffs/).
