## Read and navigate

Markdown renders as formatted reading documents; code files open with syntax highlighting. You can toggle HTML or Markdown between **Rendered** and **Source** whenever you want to inspect raw markup.

Move through the file tree using the sidebar or **Jump to file**. You can fold completed sections, mark files as viewed to track your progress, and download binary files that require external tools.

## Point to the exact detail

Highlight a text passage to discuss wording, select source lines to flag an implementation detail, or comment on the file as a whole for broader architecture feedback. Your draft comments stay attached even if you switch views.

Use the version selector to step back through earlier iterations. If you're reviewing a Git branch change rather than a file bundle, ask your agent for a [diff artifact](/docs/diffs/).
