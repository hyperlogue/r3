## Explore, then comment

An **artifact** is a piece of work and its conversation. Explore before commenting.

Select a specific target and ask for an observable change:

> Explain who can see this project before I create it.

Add several comments, then **Send to agent**. If no agent is listening, paste the **Use in agent** command into your agent’s conversation.

## Check the next version

Each publication is a saved version. Your current view stays put when a new one arrives; choose **Go to the latest version** when ready.

Open the agent’s **Fix** link or **Compare**, where available. Reply if more work is needed. **You decide when to resolve** a thread; an agent reply does not close it.

[Archive](/docs/cleanup/) finished work to keep your active list clear.
