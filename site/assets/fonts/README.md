# Example font

`Roboto.ttf` is the unmodified Roboto 3.015 variable font, released on
January 15, 2026. It supplies reproducible typography for the website’s real r3
workspace examples and their captures, including hosts with minimal system fonts.

Upstream: [Roboto 3.015](https://github.com/googlefonts/roboto-3-classic/releases/tag/v3.015).
