## 将相关的审阅分组

项目可帮助你在 Artifact 库中整齐归类相关 Artifact。当智能体从 Git 仓库进行发布时，r3 可以根据远程仓库自动对 Artifact 进行分组，或者你也可以显式指定 `--project <id>`。

## 管理项目分组

你可以通过 CLI 或网页界面创建、重命名或重新分配项目，也可以在设置中配置 Git 远程仓库别名映射。

删除项目会解散其 Artifact 的分组，但会**保留所有版本、文件和主题**。（删除单个 Artifact 仍是一项独立的永久操作）。

项目的存在是为了方便组织管理；它们不会在服务器上划分访问权限。
