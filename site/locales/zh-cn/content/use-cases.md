# Example Fieldwork

通过五个具体的 r3 演练，跟随 Example Fieldwork 经历从原型到发布的完整流程。

- [完善项目创建流程](/use-cases/prototype/)：亲自体验界面。指出令人困惑的控件。在同一对话中审阅新版本。
- [改进用户引导的界面设计](/use-cases/proposal/)：讨论需要修改的段落，配套支持文件触手可及。
- [探索搜索功能的工作原理](/use-cases/explanation/)：让智能体做一份可以动手尝试的讲解文档，再一起讨论细节。
- [修复表单重复提交](/use-cases/code-review/)：审阅真实的补丁、探讨失败场景，并检查智能体的下一次发布。
- [改进发布活动物料](/use-cases/media/)：即使资产发生变动，仍将保存的帧与区域附加在反馈中。

独立的[在线演示](/demo/)采用包含贝塞尔曲线实验室与代码审阅的场景，配合脚本化的智能体回复。
