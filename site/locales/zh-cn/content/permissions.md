## 选择页面可以访问的内容

HTML Artifact 会在浏览器中执行脚本。预览运行在不透明的沙箱中，无法访问你的 r3 身份凭据或外部网络 API。

每个 Artifact 都有独立的浏览器本地存储，与 r3 设置及其他 Artifact 隔离。重新加载和切换版本会保留这些数据；退出登录、删除 Artifact 或清除浏览器网站数据会将其移除。每个 Artifact 最多可保存 256 KiB、1,024 个键。浏览器存储不可用时，更改仅在本次工作区访问中保留。允许外部网络访问后，页面也可以将保存的状态发送到 r3 之外。

关闭工作区登录验证不会关闭预览隔离、Host/origin 检查或网络与设备的权限控制。

如果浏览器无法验证网络拦截，r3 可以提供**兼容性授权**。源隔离仍是必要条件。一旦获得许可，r3 会记住你的选择，免去重复提示的困扰。

## 仅授予任务所需的最小权限

如果原型需要第三方 API 访问，它可以请求**外部网络访问**。仅当你信任该页面时才授予此权限，因为它允许发起出站请求。只要可能，请让智能体直接将字体、图像和依赖项打包到 Artifact 中。

摄像头和麦克风访问需要 r3 与浏览器的双重显式权限提示。常驻的状态指示器允许你随时停止媒体采集。

如果预览在后台标签页挂起后暂停，点击**重试**即可重新加载沙箱，无需重新发布新版本。
